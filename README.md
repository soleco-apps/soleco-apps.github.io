# Soleco Apps — page d'accueil

Page statique (GitHub Pages) : tuiles vers les web-apps Apps Script Soleco +
icône onglet / écran d'accueil iPhone.

**Public par nécessité** (GitHub Pages gratuit) mais ne contient que des liens
et des icônes — aucun code, aucune donnée, aucun secret.

- URL : https://soleco-apps.github.io/
- Contenu : `index.html`, `site.webmanifest`, `assets/` (icônes PNG)

Pour changer une URL d'app : éditer le `href` de la tuile dans `index.html`
(l'URL `…/exec` du déploiement web de l'app). Un `git push` sur `main` republie.
